An AI agent you can hand work to,
running only on your own server

Just talk to it in the browser chat, and the AI plans and carries out tasks such as reading and creating Excel, Word, PowerPoint and PDF files, checking images, and processing many files in a folder at once. Name origin: Local + 小羽 (cohane, a Japanese name meaning "small feather")

A PoC before adopting a full AI platform

Try out how an AI agent works for your company and what it brings, on your own work, without sending internal data outside. If you are considering handing tasks to AI, such as Copilot Cowork in Microsoft 365 Copilot or Claude Cowork, you can try that idea out on your own work first.

🧪

Skill development for your own work

Staff turn their usual procedure into a draft skill just by talking it through in the chat. A developer then uses the "Skill Lab" to build evaluation cases, let the AI fix its problems, and publish it as an official skill for the department once it passes repeated evaluations.

📊

Admin dashboard

Change AI endpoints and settings, start and stop instances per department, and check status, conversations and logs in the browser. Describe a problem in "Ask AI" and it tells you which setting to change.

💴

Estimating AI usage costs

Token usage is totaled by month, department and user. Enter your AWS pricing (hourly GPU instances or per-token pricing such as Bedrock) to estimate the cost of a full rollout.

📐

CAD features for design work

Show STEP, IGES, DXF and STL in a 3D viewer in the chat and click faces or parts to point at them. It also handles hole and volume checks, differences from the previous version, and STEP PMI (dimensions and tolerances).

Features

Designed for specialized work where mistakes are not acceptable, such as engineering design. Rather than raw AI capability, it puts getting the same result every time (reproducibility) first.

🔒

Fully offline

The AI model runs on your own server, so conversations and files are never sent outside. No external communication by default.

✅

Approve the plan first

Work that can change files shows a checklist plan first and proceeds only after you approve it (automatic approval can be configured).

🛡️

No arbitrary commands

No general-purpose shell. The AI can only run the scripts of prepared skills and Python code with safety guards.

🪶

Stable with smaller models

Many safeguards against runaway behavior and mistakes let it finish the job without an expensive large model.

📘

Learns work through skills

Write a procedure as a SKILL.md and the AI works the same way. It follows the Agent Skills standard, so skills move with you to a future AI platform.

👥

Shared by a team, PC and phone

Several people can use one server at once (with sign-in). The chat and admin tool work in PC and smartphone browsers, in Japanese or English.

Screens

Which skill the AI reads and which tool it uses are shown on screen as steps, so you can follow its progress. (Screenshots show the Japanese UI.)

View 3D CAD in the chat and point at it Experimental

  • View: rotate and zoom, toggle parts and layers, change colors
  • Point and ask: click faces, edges, vertices or parts and say "make a 5 mm hole in this face"
  • Create: ask "make a gear" and the AI builds it with CadQuery and shows it
  • Take it home: save as STEP, DXF or colored STL

For administrators: settings dashboard

  • Change AI endpoints, settings and sign-in users in the browser
  • Start, stop and restart multiple instances per department or role
  • Usage and cost estimates; status, conversations and logs
  • Skill Lab: evaluate draft skills, let the AI fix them, and promote them
  • Manage memory and knowledge (semantic search of internal documents)

Get started

Requirements: Windows (tested on Windows 11), a Python 3.11 virtual environment, an inference server with an OpenAI-compatible endpoint (tested with llama.cpp's llama-server, vLLM, Strata, etc.) and a model file. A GPU is recommended (the developer tests with an RTX 5060 Ti 16GB + Qwen3.6-35B-A3B).

Set the Python environment and install dependencies

Copy python_env.bat.example to python_env.bat and set PYTHON_DIR.

call python_env.bat
python -m pip install -r requirements.txt

Start the inference server

Example: llama-server (listening on http://localhost:8080/v1)

llama-server --model C:\path\to\model.gguf --alias local-model --host 127.0.0.1 --port 8080 -c 8192

Prepare admin tool sign-in

Copy .env.example to .env and set ADMIN_USERS.

ADMIN_USERS=[["admin", "change-me"]]

Start it

admin.bat starts the admin tool (http://127.0.0.1:8001) and Locohane itself. On first launch, a getting-started tutorial walks you from setting the AI endpoint to opening the chat screen at http://127.0.0.1:8000.

Licenses differ from model to model. Always check them for commercial use (models under Apache 2.0 are a safe choice if in doubt). For details, see README_DETAIL.en.md "Setup and startup".
